Internet and web fundamentals

What is the internet? How does it work? What is the web? How do they work? What is the difference between the internet and the web?

Internet

Internet is a global network of interconnected computers and servers that communicate with each other using standardized protocols.

Web

The web is an information system where documents and other resources are identified by URLs, and can be accessed over the internet.

OSI model

The OSI (Open Systems Interconnection) model is a conceptual framework used to understand and standardize the functions of a networking system.

DNS

DNS (Domain Name System) is a hierarchical and decentralized naming system for computers, services, or other resources connected to the internet or a private network.
